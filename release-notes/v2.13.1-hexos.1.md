## What's new in HexOS v2.13.1-hexos.1

Based on upstream [ESP-Miner v2.13.1](https://github.com/bitaxeorg/ESP-Miner/releases/tag/v2.13.1).

---

### HexOS branding

- HexOS gothic logo on first boot splash; HeliosPool logo on second boot splash
- HexOS vector SVG logo in the web UI topbar
- Firmware log tag and boot message changed to `HexOS`
- Web UI page title, route titles, and all UI labels updated to HexOS
- OTA firmware/www file prefix checks updated to `hexos-firmware-*` / `hexos-www-*`
- GitHub update service pointed at `heliospool/HexOS` releases
- Log download filename prefix changed to `hexos-logs-`
- Updated favicon

### Helios Pool integration

- Account stats banner on the home dashboard showing hashrate, workers, and earnings from the Helios Pool API
- Same stats banner shown in the swarm view per-device

### GekkoAxe hardware support

- **GekkoAxe GT** — dual BM1370, 12 V, up to 60 W (`gekko-800` board)
- **GekkoAxe γ (Gamma) 5 V** — single BM1370, 5 V, up to 40 W (`gekko-601` board)
- **GekkoAxe γ (Gamma) 12 V** — single BM1370, 12 V, up to 50 W (`gekko-601-12` board)
- Per-device TPS546 VIN limit configuration via NVS
- Self-test `power_consumption_target` for `gekko-800` corrected to 36 W

### BCH mining support

- **Decode Coinbase Tx** is now a dropdown: **Auto / BTC / BCH / Disabled**
- **Auto** (default) detects BTC or BCH from your payout address — no configuration needed
- BCH outputs decode with correct CashAddr encoding
- Share star (★) and percentage work correctly for BCH pools across all address formats

### Expert Mode

- New **Expert Mode** toggle in Settings
- When enabled, ASIC frequency and core voltage switch from safe preset dropdowns to free-entry inputs
- Setting persists across reboots

### Fan controller improvements

- Auto fan continues working if any individual ASIC temperature sensor stops reporting
- Fails safe to 100% speed if all sensors are lost
- More aggressive response to rising temperatures; gradual spin-down prevents oscillation
- Fan PID gains and decrease rate configurable via NVS (`pid_p`, `pid_i`, `pid_d`, `fan_dec_rate`)

### Danger Zone NVS tuning

Advanced tuning parameters configurable via CVS file without editing source code.
Add `dangerzone,data,u8,1` to your CVS to unlock:

- **Thermal thresholds** — `throttle_temp`, `safe_temp`, `vr_thr_temp`
- **ASIC frequency reduction step** — `asic_reduction`
- **TPS546 VIN limits** — `vin_on`, `vin_off`, `vin_ov_fault`
- **Fan PID gains** — `pid_p`, `pid_i`, `pid_d`, `fan_dec_rate`

Available without `dangerzone=1`:

- **Stratum connection tuning** — `strat_retry`, `strat_crit_rty`, `strat_timeout`
- **Self-test parameters** — `st_difficulty`, `st_pwr_margin`, `st_vcore_min`, `st_vcore_max`

See [doc/configuration.md](https://github.com/heliospool/HexOS/blob/master/doc/configuration.md) for all keys, types, and defaults.

### Board temperature

- EMC fan controller internal die temperature exposed as `boardTemp` in `/api/system/info`
- Shown as a progress bar in the Heat card; available as a chart series on the dashboard

### Jobs counter

- Stratum work received since last pool connection exposed as `workReceived` in `/api/system/info`
- Shown in the Shares card

### Bug fixes

- UI release notes parser no longer corrupts markdown links with adjacent URLs
- `GekkoAxe-γ` family name no longer has a spurious `-12` suffix
- NVS migration for `800` → `gekko-800` board version key

## Flashing

**AxeOS UI (OTA update — no USB required):**
1. Settings → Update Firmware → upload `HexOS-v2.13.1-hexos.1-firmware.bin`
2. Settings → Update HexOS → upload `HexOS-v2.13.1-hexos.1-www.bin`

**Clean flash via esptool (USB):**
```bash
esptool.py --chip esp32s3 -b 460800 write_flash 0x0 HexOS-v2.13.1-hexos.1-factory-<board>.bin
```

**Clean flash via bitaxetool (USB, with config):**
```bash
pip install bitaxetool==0.6.1
bitaxetool --config config-<board>.cvs --firmware HexOS-v2.13.1-hexos.1-factory-<board>.bin
```
